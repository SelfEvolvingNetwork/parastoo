ورود به گیت (SSO)

پوش از خط فرمان (شما یا عامل‌تان) هم از یک مسیر می‌گذرد: ریموت پل {{ panel_url }}/bridge/git/{{ p.slug }}.git — نام‌کاربری دلخواه، رمز = توکن عامل همین پروژه (کارت پایین‌تر). توکن داخلی گیتا فقط داخل موتور پرستو مصرف می‌شود و هرگز نمایش داده نمی‌شود.

با هر push به شاخهٔ main، بیلد خودکار شروع می‌شود و همهٔ سرویس‌های پروژه با ایمیج جدید مستقر می‌شوند.

چند-کانتینری: تعریف سرویس‌ها با parastoo.yml 
# parastoo.yml در ریشهٔ مخزن — هر تعداد سرویس
parastoo: 1
services:
  web:                # فقط سرویس عمومی دامنه می‌گیرد
    build: .
    port: 3000
    public: true
    env: [DATABASE_URL=postgres://db:5432/app]
  db:                 # داخلی — فقط داخل شبکهٔ خصوصی همین پروژه
    image: postgres:16-alpine
    volume: dbdata:/var/lib/postgresql/data

نام هر سرویس داخل شبکهٔ خصوصی پروژه به‌عنوان نام میزبان به بقیه می‌رسد (مثلاً db:5432). سرویس‌های داخلی از اینترنت در دسترس نیستند.
